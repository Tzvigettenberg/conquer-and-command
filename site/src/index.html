HOW TO PLAY

Everyone downloads the same build

Unzip and run ConquerAndCommand.exe. Windows may warn about an unknown publisher the first time — More info → Run anyway. Everyone needs the same version, so grab the newest zip whenever there's an update.

One person creates a game

Type a name for it, add a password if you only want your own crowd in it, and press Create game. Matches run on our server, so there is nothing to set up: no port forwarding, no addresses, no router settings. It works the same whether your friend is next door or on the other side of the world.

Friends pick it from the list and go

Your game appears in everyone's Open games list — one click and they are in your lobby. You pick the map (2 to 6 spawn slots), factions, teams, starting cash and superweapons, and everyone sees every change as you make it. Fill spare slots with AI generals, or press Observe to watch instead of playing. When everyone's in, Start.

Playing alone? Skirmish vs AI runs entirely on your own PC — no connection needed — and you can set every slot to an AI and just watch them fight.

CONTROLS

The Generals layout, so your hands already know it.

Left-dragSelect — double-click grabs every unit of that type on screen, Shift adds
Right-clickMove, attack, repair, gather, capture, board — Shift queues
A + clickAttack-move — works on the minimap too
Q / W / ESelect all combat units / aircraft / same type on screen (tap twice for the whole map)
GGuard an area — drag to size the circle
S · XStop · scatter (or force-fire with a target)
N · Ctrl+UpNext Dozer / Worker · next builder
B F I C YJump to Barracks / War Factory / Airfield / Command Center / Supply Center
Ctrl+1…9Control groups — press twice to jump there
H · SpaceHome base · last attack alert
[ ] · wheelRotate · zoom (middle-drag tilts, numpad 5 resets)
EnterChat with everyone (Backspace: allies only) · Ctrl+B drops a beacon
